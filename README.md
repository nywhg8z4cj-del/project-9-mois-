# project-9-mois-

Jeu Roblox d'histoire / roleplay : PNJ avec dialogues à choix, quêtes, zones, objets à ramasser et sauvegarde.

- `src/ServerStorage/StoryConfig.lua` — l'histoire (PNJ, dialogues, quêtes, zones, objets)
- `src/ServerScriptService/StoryServer.server.lua` — la logique serveur
- `src/StarterPlayer/StarterPlayerScripts/StoryClient.client.lua` — l'interface du joueur

👉 Installation pas à pas dans Roblox Studio : voir [GUIDE.md](GUIDE.md).
