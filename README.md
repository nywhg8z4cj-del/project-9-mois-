# Trouve le Joker 🃏

Petit jeu de cartes dans le navigateur, inspiré de la bataille.

- 45 cartes face cachée : 44 cartes tirées au hasard d'un jeu de 52 + **1 Joker**
- Les cartes sont mélangées aléatoirement à chaque partie (mélange de Fisher-Yates)
- Retourne les cartes une par une pour trouver le Joker
- Une pluie de paillettes ✨ quand tu trouves le Joker
- Bouton **Rejouer** pour recommencer autant de fois que tu veux
- Compteur de cartes retournées, de parties gagnées et meilleur score (gardés dans le navigateur)

## Jouer

Ouvre simplement `index.html` dans ton navigateur (double-clic sur le fichier). Rien à installer.
