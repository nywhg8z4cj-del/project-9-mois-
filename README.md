# Barley on the Hudson

One-page restaurant site (Tarrytown, NY) styled with the "Amrit Palace" parchment/saffron editorial design system.

Styles live in `styles.css`.

## Voir le site en local (localhost)

Double-clique sur le lanceur de ton système : le site s'ouvre dans ton navigateur sur **http://localhost:8000**.

- **Mac / Linux :** `lancer-site.command` (nécessite Python 3).
- **Windows :** `lancer-site.bat` (utilise PowerShell, déjà installé sur Windows).

Laisse la fenêtre du terminal ouverte tant que tu regardes le site ; ferme-la pour l'arrêter. Si le port 8000 est occupé, le lanceur prend le suivant (8001, 8002…).

Sans lanceur, tu peux aussi simplement ouvrir `index.html` dans ton navigateur.
