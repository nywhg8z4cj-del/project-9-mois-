# Feuille de Stats Basket

Application web (un seul fichier, `index.html`) pour compter les statistiques de son équipe pendant un match de basket. Ouvre `index.html` dans un navigateur, sur téléphone ou tablette.

## Fonctionnalités

- **Tableau de marque** : score des deux équipes, période (Q1 à Q4, prolongations), fautes d'équipe par période avec alerte de pénalité à partir de 4.
- **Saisie rapide** : touche un joueur puis une stat :
  tirs à 2 pts, 3 pts et lancers francs (réussis / ratés), rebonds offensifs et défensifs, passes décisives, interceptions, contres, balles perdues, fautes.
- **Adversaire** : boutons +1 / +2 / +3 et faute.
- **Joueurs sur le terrain / banc**, voyants de fautes (5 fautes = éliminé).
- **Annuler** la dernière action ou supprimer n'importe quelle action du journal.
- **Feuille de stats** : PTS, tirs, %, 3 pts, LF, RO/RD/RB, PD, INT, CT, BP, F et évaluation, totaux d'équipe, score par période.
- **Export CSV** (séparateur `;`, compatible Excel).
- **Sauvegarde automatique** dans le navigateur : un rechargement de page ne perd pas le match.

Au premier lancement, un match d'exemple est affiché. Onglet **Effectif** → saisis tes joueurs, puis **Nouveau match**.
