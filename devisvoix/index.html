Comment ça marche

  1. Vous dictez : le client, ce qu'il faut faire, les quantités, le temps passé.
  2. L'appli reconnaît vos prestations et prend vos prix (onglet « Mes prix »).
  3. Vous vérifiez, corrigez une ligne si besoin, puis vous téléchargez le PDF.
